BASE PROJECT
------------
Input project: RodBot_CAN_Scanner_V3_Modified(3).zip
The existing CAN, OBD-II, GPS, encoder, startup-diagnostics, Serial UI, HTTP,
and WebSocket logic was retained. The TFT is a new renderer consuming the same
UiModel/UiFrame used by the phone and Serial interfaces.

TARGET TFT WIRING
-----------------
Shared SPI SCK:   GPIO5
Shared SPI MOSI:  GPIO18
Shared SPI MISO:  GPIO19
MCP2515 CS:       GPIO23
TFT CS:           GPIO12
TFT DC:           GPIO14
TFT RESET:        GPIO15

GPIO12/GPIO14 are the confirmed working TFT control pins on the assembled
unit. The earlier GPIO22/GPIO21 assignment caused unresolved hardware behavior
and is no longer used.

The firmware targets an ILI9341-compatible 240x320 SPI module in landscape
rotation, producing a 320x240 UI. The TFT LED/backlight pin is not driven by
software in this version.

FIRST-BOOT NOTES
----------------
- If the image is upside down, change AppConfig::TFT_ROTATION from 1 to 3.
- If the backlight turns on but no graphics appear, verify ILI9341 compatibility,
  TFT CS GPIO12, DC GPIO14, RESET GPIO15, shared SCK/MOSI, and common ground.
- If colors are incorrect on the clone, display inversion or RGB/BGR settings
  may require a small controller-specific adjustment after the first test.
