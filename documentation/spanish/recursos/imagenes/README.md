# Imágenes de la documentación de RoadLink

En este directorio se guardan fotografías, diagramas, capturas de pantalla y otras evidencias visuales utilizadas en los documentos en español de cada módulo.

Utilice nombres de archivo descriptivos, en minúsculas y separados mediante guiones, por ejemplo: `esp32-sim800l-montaje-prueba.jpg`. Antes de publicar una imagen, elimine información privada como números telefónicos, identificadores de tarjetas SIM, contraseñas, claves de API y direcciones privadas de servidores.

Para cada imagen, registre la fecha aproximada, el hardware o la prueba que muestra y la conclusión que el lector debe obtener de ella. Esta información debe aparecer en la descripción de la imagen dentro del documento correspondiente.

- `conector-obd2-montaje-roadlink.jpg`: conector OBD-II instalado en el gabinete del prototipo. Fotografía proporcionada por el autor; fecha de toma no registrada. Muestra el montaje exterior, pero no verifica el pinout ni una comunicación CAN exitosa.
- `can-estadisticas-pantalla-roadlink.jpg`: pantalla de estadísticas CAN; fecha, vehículo y configuración de captura no registrados. Permite transcribir los contadores visibles, no reconstruir la traza original.
- `obd2-datos-vivos-pantalla-roadlink.jpg`: pantalla con una instantánea de datos OBD-II decodificados; fecha y vehículo no registrados. No demuestra que los valores se estuvieran actualizando al tomar la fotografía.
