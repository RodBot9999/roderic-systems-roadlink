# RoadLink documentation images

Store photographs, diagrams, screenshots, and other visual evidence for the module documents in this directory.

Use descriptive lowercase file names separated by hyphens, such as `esp32-sim800l-test-setup.jpg`. Before committing an image, remove private information such as telephone numbers, SIM identifiers, passwords, API keys, and private server addresses.

For each image, record its approximate date, what hardware or test it shows, and what conclusion the reader should draw from it. This information should appear in the caption in the relevant document.
